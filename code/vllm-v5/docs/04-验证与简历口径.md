## 4. Decode CUDA Graph / Prefill torch.compile / paged attention

| 项 | 位置 | 开关 |
|---|---|---|
| Decode CUDA Graph（含 MoE，workspace 池化） | `src/compute/cuda_graph.py`、`src/compute/model_runner.py` | `--cg` |
| Prefill `torch.compile` | `src/compute/model_runner.py` | `--compile` |
| **FlashAttention paged** attention（`flash_attn_with_kvcache` / `flash_attn_varlen_func`），替代 v2 的逐样本 gather+SDPA | `src/compute/layers/attention.py` | 默认 |

> ⚠️ 口径修正：本项目的 paged attention 后端是 **FlashAttention (FA2 paged)**，
> 不是 FlashInfer。FlashInfer 在本仓库只用于 **MoE cutlass fused 后端** 和
> RoPE / RMSNorm / SiLU 等算子（`src/compute/layers/ops.py`、`src/moe/fused.py`）。
> 简历若写「以 FlashInfer paged attention 替代 gather+SDPA」与代码不符，建议改成
> 「以 FlashAttention paged attention 替代逐样本 gather+SDPA」。

「gather+SDPA → paged attention」的对照实验在 `vllm-v3/bench/bench_decode_attention.py`。

验证：

```bash
pytest tests/gpu/test_moe_cudagraph.py -q --tb=short   # CG 与 eager 结果一致
pytest tests/gpu/test_dense_smoke.py -q --tb=short
```
